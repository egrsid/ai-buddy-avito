# S1 · Контекстный AI-чат

Версия 1.0 · статус: спецификация для реализации, не готовая фича.
Владельцы: AI + Backend + Frontend. Задачи: AI-01/02/03, BE-03, FE-03.

## Критерии приёмки

- [ ] Общий чат и отдельный диалог задачи не смешивают историю.
- [ ] AI объясняет несколько терминов, показывает реальные источники и следующий шаг.
- [ ] Неизвестный термин не выдумывается; предлагается передача buddy.
- [ ] SSE показывает ожидание/текст/источники; после refresh завершённые сообщения сохраняются.
- [ ] Обрыв и cancel сохраняют частичный ответ с корректным статусом; retry не дублирует user message.
- [ ] Инструкции в KB не дают права на действия; AI сам не исполняет tools.

## Границы

Только intern/buddy, синтетические данные, без HR и реальных корпоративных прав.
Поведение API/security/state-machines обязательно; изменение через TL review.

## Ручная проверка

На fixture MR получить source. На неизвестный термин — признание неопределённости. Оборвать поток: run interrupted, refresh без фиктивного completed. Retry создаёт новый run на прежний user message.
