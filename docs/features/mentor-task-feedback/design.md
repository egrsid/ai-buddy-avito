## Компоненты

Go считает distinct, окно и дедуп в транзакции, резервирует report до AI. Python получает только safe aggregate + разрешённый раздел/refs и возвращает гипотезу/предлагаемую формулировку; offline создаёт ту же карточку. Наставник вручную редактирует ТЗ.

## Ошибки и совместимость

DB error и пользовательская неясность — разные типы доказательств. Report не обвиняет наставника и не является HR-оценкой. Нет IDs/списка стажёров, raw chats/PII/Telegram; при count=2 не обещается абсолютная анонимность.

Новые таблицы и contract schemas поставляют владельцы после V3-CONTRACT-01. Новые SQL
migrations, idempotency/expected_version и restart tests обязательны. Старые данные не
переписываются ради demo. [Порядок работ](../../v3/delivery.md).
