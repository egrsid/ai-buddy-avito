# S2 · План адаптации

Версия 1.0 · статус: спецификация для реализации, не готовая фича.
Владельцы: Backend + Frontend. Задачи: BE-02, FE-01/02, QA-01.

## Критерии приёмки

- [ ] Стажёр входит и получает только свои синтетические задачи, прогресс и следующий шаг.
- [ ] Открывает детали и отдельный чат задачи; сервер проверяет владение.
- [ ] Явно меняет статус, после refresh/restart видит сохранённое значение.
- [ ] Устаревший version даёт 409 без перезаписи; создание заявки не завершает задачу.
- [ ] Buddy и второй стажёр не читают чужие задачи; пустой список даёт прогресс 0.

## Границы

Только intern/buddy, синтетические данные, без HR и реальных корпоративных прав.
Поведение API/security/state-machines обязательно; изменение через TL review.

## Ручная проверка

Войти intern-a, сменить todo → in_progress, обновить страницу и сервис. Убедиться в сохранении. Повторить старый version → 409; intern-b не читает ID intern-a.
