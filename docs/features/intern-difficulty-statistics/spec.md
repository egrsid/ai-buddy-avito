# Статистика затруднений для наставника и владельца документов — specification v3

PLANNED, не реализовано. Задачи V3-STATS-BE-01, V3-STATS-FE-01.
[Общий план](../../v3/delivery.md), [Product](../../v3/product.md).

Статистика доступна как отдельный раздел для наставника и владельца документации,
не только в карточках кандидатов. Один человечески читаемый экран показывает период,
число затронутых стажёров, типы/места затруднений, частоту и динамику. Нет рейтинга людей
и выводов «стажёр слабый»/«наставник плохо работает» по числам.

Наставник: (а) технические затруднения явно назначенных ему стажёров в разрешённой области;
(б) агрегаты неясности собственных ТЗ по версии/разделу/причине. Эти вкладки не суммируются
в один счётчик: автор ТЗ и личный наставник могут различаться. Владелец документов: только
проблемы шагов с назначенными ему instruction refs/versions и связанные candidates.
Он не получает личные сообщения, индивидуальный прогресс и отчёты по чужим ТЗ.

Фильтры P0: период 7/30/90 дней (по умолчанию 30), разрешённые goal/journey/step или
brief/version/section, reason/error, status. Только фиксированные разрешённые разрезы,
без фильтра intern/name или выгрузки сырых событий. Никаких новых ролей.
Карточки: уникальные затронутые стажёры, принятые наблюдения, открытые blockers, распределение
по проблемам, связанные отчёты/их review state, дневная динамика. Сортировка по affected
count с устойчивым tie-breaker, подпись «данные на …». Empty не путать с ошибкой загрузки.

По умолчанию частотные строки/графики с менее чем 2 distinct стажёрами скрывают точные
значения как «недостаточно данных», не показывают 0. Это privacy baseline, не обещание
абсолютной анонимности. Нет drill-down до имён/чатов. Не раскрывать подавленную группу
через totals/вычитание/малые buckets: suppression применяется к totals, daily buckets и
долям тоже. Порог privacy отдельно от порога создания report: карточки кандидатов не
создаются и не меняют состояние от посещения статистики.

UI не предлагает произвольное исправление документа/ТЗ по графику: ведёт в разрешённый
report или редактор; публикация человеком сохраняется. Возможен zero candidates при
наличии наблюдений: статистика и автоматический threshold pipeline не одно и то же.
