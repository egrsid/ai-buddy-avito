# S4 · Вопрос наставнику

Версия 1.0 · статус: спецификация для реализации, не готовая фича.
Владельцы: Backend + AI + Frontend. Задачи: BE-06, FE-04.

## Критерии приёмки

- [ ] Стажёр видит и подтверждает точные question/summary/source_ids и получателя.
- [ ] Buddy получает только обращения назначенных стажёров без личной истории.
- [ ] Непустой ответ и resolved фиксируются атомарно кнопкой «Ответить и закрыть».
- [ ] Стажёр видит ответ после polling/refresh; повтор с тем же ключом не создаёт второй ответ.
- [ ] Ответ не публикуется в KB; другой buddy и intern не читают обращение.

## Границы

Только intern/buddy, синтетические данные, без HR и реальных корпоративных прав.
Поведение API/security/state-machines обязательно; изменение через TL review.

## Ручная проверка

intern-a подтверждает preview; buddy-b получает 404 по ID; buddy-a отвечает и закрывает. intern-a видит answer/resolved, intern-b — 404. В KB нового документа нет.
