# Вопрос наставнику с диагностическим контекстом — спецификация

## Цель и предусловия

Intern имеет собственную goal/step либо assignment/section; назначенный buddy и его контакт известны или явно отсутствуют.

## Пользовательский сценарий

Intern формулирует вопрос → Go собирает разрешённые факты → AI готовит краткую выжимку либо rule-based fallback → preview → copy/open Telegram → ручная отправка человеком.

## Правила и критерии приёмки

- **CONTACT-01.** Preview использует пересечение прав отправителя и получателя. Закрытые названия, raw logs, DSN, секреты и полная история чата исключены.
- **CONTACT-02.** Модель получает только безопасные факты и ограниченный вопрос. Инъекция/секреты/неподтверждённые утверждения приводят к безопасному шаблону.
- **CONTACT-03.** Preview привязан к context/version/TTL; изменение текста/прав/assignment требует нового preview. Экспорт возвращает тот же сохранённый текст.
- **CONTACT-04.** Открытие Telegram и copy не означают отправку, доставку, ответ, устранение blocker или verified.
- **CONTACT-05.** При отсутствии контакта показано понятное состояние. Новый внутренний inbox/отправка не создаются; legacy обращения доступны только read-only по ACL.

## Контрольный пример

При DB_SSL_REQUIRED получатель видит учебный ресурс, безопасный код ошибки и вопрос «Какой режим SSL выбрать?». Стажёр проверяет текст до копирования; система не заявляет доставку.
