# Единое рабочее пространство — specification v4

Target specification. [Текущая реализация и приёмка](../../final-acceptance-2026-11-14.md). [Product](../../product.md), [delivery](../../delivery.md).
Задачи: V4-WORK-BE-01, V4-WORK-FE-01.

Стажёр видит все свои рабочие результаты сразу: название, зачем, pinned ТЗ, техническую
готовность, blocker и одно следующее разрешённое действие. Технические подзадачи раскрываются
независимо. Несвязанные ТЗ и goals доступны как понятные карточки «связь не задана».

Автор выбирает разрешённый template при назначении, intern подтверждает связь.
Existing assignment получает отдельный preview/confirm; связи по названию/AI запрещены.
Разные задания могут ссылаться на один goal, но verified не удваивается в общей статистике.
Нет общего процента «принято ТЗ + IAM». Человеческая приёмка результата — P1.

Telegram вопрос идёт из точного section/step context, форма раскрывается и получает фокус.
Действие при pending заблокировано. Empty/error/revoked состояния различаются.
Работа с неподтверждённым ТЗ не делает technical ready. После всех технических goals —
поздравление без повторного назначения того же маршрута.

Приёмка: V4-T01–T04 в [матрице](../../testing.md).
