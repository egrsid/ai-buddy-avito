# Аутентификация и доступ v1

Статус: контракт реализации; endpoints ещё не реализованы. Все решения относятся к синтетическому MVP.

## Вход

POST /api/v1/auth/demo-login с {"account_id":"intern-a"} разрешён только local/test.
Допустимые аккаунты: intern-a, intern-b, buddy-a, buddy-b. Паролей в демо нет.
Go создаёт 32 случайных байта сессии, хранит SHA-256 токена в app.sessions,
возвращает cookie buddy_session (HttpOnly, SameSite=Lax, Path=/, max-age=28800).
Secure=true при HTTPS; локальный HTTP — единственное исключение. Роль берётся только из БД.
Повторный вход отзывает текущую cookie-сессию. POST /auth/logout отзывает сессию и удаляет cookie.

GET /auth/me возвращает пользователя и csrf_token; token хранится только в памяти frontend.
Все изменяющие запросы, включая login/logout, проверяют точное Origin из APP_ORIGIN.
Кроме login, требуют X-CSRF-Token, привязанный к сессии; отсутствие/несовпадение → 403.
Браузер обращается через Vite proxy к /api; CORS по умолчанию закрыт.
Сессия истекает через 8 часов без продления. Нет localStorage JWT.

## Матрица

| Ресурс/операция | Intern | Buddy |
|---|---|---|
| Собственный профиль | Читать | Читать |
| Задачи и прогресс | Только свои; менять статус своих | Нет доступа |
| Диалоги, сообщения, runs, actions | Только свои | Нет доступа |
| Заявки | Только свои; подтверждать свои предложения | Нет доступа |
| Обращения | Создавать и читать свои | Читать и отвечать только назначенным стажёрам |
| Документы знаний | Читать общие синтетические | Читать общие синтетические |
| Изменение KB, выдача прав, HR | Запрещено | Запрещено |

Для чужого или отсутствующего объекта одинаковый 404. Для запрещённого роли маршрута 403.
Go не доверяет user_id, role, buddy_id из браузера или модели: получает их из сессии/БД.
Buddy видит снимок явно переданных question/summary/source_ids, без полной истории.
Повторная проверка назначения перед ответом buddy обязательна. Назначения в MVP seed-only.

## Внутренние вызовы

Go → AI и Go → mock: Authorization: Bearer INTERNAL_API_TOKEN. Сервисные порты не
публикуются на хост. Token обязателен, сравнивается constant-time, не выводится в логи.
Healthcheck не требует token и не содержит данных. Браузер не получает внутренний token.
Python возвращает только документы visibility=demo_public. Введение закрытых документов
требует новой ACL-спецификации и тестов фильтрации до LLM и при открытии источника.

## Данные и ограничения

Только синтетические документы. Логи содержат request_id, длительность, тип/результат операции;
без тела чата, cookie, ключей и полного контекста. Аудит хранит IDs, тип, снимок разрешённых
параметров и результат. История хранится до явного локального reset; плановая retention
для публичного сервиса проектируется отдельно. В LLM уходит максимум 20 последних завершённых
сообщений текущего диалога, не более 12000 символов, плюс текущая задача и до 5 фрагментов KB.
Максимум сообщения 4000 символов, summary 2000, вопроса buddy 4000, обоснования 1000.
Никаких секретов и пользовательских прав в prompt. Инструкции из найденных документов
считаются данными, не меняют инструменты и правила доступа. Markdown рендерится без raw HTML.
