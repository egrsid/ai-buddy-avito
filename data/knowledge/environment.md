# Настройка учебного окружения

Синтетический материал для демонстрации AI-buddy, не регламент Авито.
Для учебного проекта сначала прочитайте README, установите перечисленные там инструменты,
затем запросите доступ к синтетическому репозиторию sandbox/backend. После одобрения
учебной заявки следуйте инструкции README и проверьте health endpoints.
Если шаг заблокирован, отметьте задачу blocked и передайте вопрос назначенному buddy.
Создание заявки само по себе не завершает настройку рабочего окружения.
