# Как устроены цели, проверки и помощь buddy

Синтетический учебный материал для демо AI-buddy, не регламент Авито.

Цель — инженерная задача стажёра, например получить доступ к тестовой базе и проверить
подключение. Цель состоит из шагов, у каждого шага есть проверка.

Шаг считается выполненным только после доверенной проверки: её результат приходит от
системы, а не из сообщения в чате. Подсказка AI или ответ buddy — это помощь, а не
доказательство выполнения.

Если шаг заблокирован, в карточке видно код ошибки и допустимые действия: повторить
проверку, оформить заявку или эскалировать вопрос buddy. При эскалации buddy получает
краткую диагностическую сводку без полной переписки и без секретов.

Короткий словарь:

- БД — база данных.
- SSL — шифрование соединения с базой.
- IAM — система управления правами доступа.
- db_reader — учебная роль только на чтение.
