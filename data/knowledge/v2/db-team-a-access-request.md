# Заявка на роль db_reader для db-team-a-test

Синтетический учебный материал для демо AI-buddy, не регламент Авито.

Для тестовой базы команды A стажёру доступна только роль db_reader (чтение). Роли admin
и write в учебной среде не выдаются.

Как оформить заявку:

1. В карточке шага «Проверить доступ» нажмите «Запросить доступ». AI-buddy подготовит
   черновик: ресурс, роль и причину.
2. Проверьте черновик и подтвердите отправку. После подтверждения заявка в статусе
   submitted — это значит только «отправлена», доступа ещё нет.
3. Заявку рассматривает назначенный approver. Статус approved означает решение approver,
   но роль появляется не мгновенно.
4. Доступ есть только тогда, когда проверка «Есть роль db_reader» прошла успешно.
   Отметка «я получил доступ» или ответ в чате доступ не подтверждают.

Если заявка отклонена (rejected), прочитайте причину и обсудите её с buddy.
